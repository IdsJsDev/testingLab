# Локальный MCP-сервер

> Статус: первая рабочая read-only версия.

## Назначение

Встроенный MCP-сервер позволяет любой программе с поддержкой MCP передавать ИИ-модели актуальное состояние испытательного стенда. Сервер запускается и останавливается вручную на вкладке `MCP` и не нужен для обычной работы приложения. Доступны локальный режим и публикация через отдельно запущенный HTTPS-туннель.

## Подключение

- транспорт: MCP Streamable HTTP;
- адрес: `http://127.0.0.1:8765/mcp`;
- доступен только на компьютере, где запущено приложение;
- авторизация: `Authorization: Bearer <токен>`;
- токен генерируется заново при каждом запуске приложения и показывается на вкладке `MCP`.

Универсальный пример конфигурации:

```json
{
  "mcpServers": {
    "uav-test-station": {
      "type": "http",
      "url": "http://127.0.0.1:8765/mcp",
      "headers": {
        "Authorization": "Bearer <токен из приложения>"
      }
    }
  }
}
```

Точное место размещения конфигурации зависит от выбранного MCP-клиента. Готовую конфигурацию с текущим токеном можно скопировать из приложения.

### Публичный режим через туннель

Приложение намеренно продолжает слушать только `127.0.0.1:8765`. Для временного внешнего доступа нужно отдельно запустить HTTPS-туннель, например:

```shell
ngrok http 8765
```

На вкладке `MCP` следует выбрать `Через туннель`, заменить переменную `https://YOUR-TUNNEL-DOMAIN.ngrok-free.app` на выданный сервисом адрес и включить сервер. Приложение добавит публичный домен в разрешённые `Host` и `Origin`, а при копировании подставит публичный URL. Переключать режим и адрес можно только при выключенном сервере.

Публичный URL не запускает туннель автоматически и не публикует порт сам по себе. После завершения работы следует выключить MCP-сервер и процесс туннеля.

## Доступные инструменты

- `get_connection_status` — состояние подключений контроллера и амперметра;
- `get_telemetry` — последний снимок MAVLink-телеметрии;
- `get_ammeter_reading` — последнее измерение внешнего амперметра;
- `list_parameters` — поиск параметров в локальном кэше приложения;
- `get_parameter` — получение одного параметра по точному имени.

Первая версия работает только на чтение. В MCP намеренно нет записи параметров, ARM/DISARM, эмуляции RC, запуска моторов или иных управляющих воздействий.

## Контроль доступа и журнал

Вкладка показывает клиентов, обращавшихся после запуска сервера, время последнего запроса, число запросов и последние разрешённые либо отклонённые обращения. HTTP не поддерживает постоянное соединение для каждого клиента, поэтому список означает «недавно обращавшиеся клиенты», а не гарантированно открытые в данный момент TCP-соединения.

Сервер привязан к loopback-интерфейсу, проверяет заголовки `Host` и `Origin`, а также bearer-токен. Без отдельно запущенного туннеля он не доступен другим компьютерам локальной сети или из интернета.

## Дальнейшее развитие

Перед добавлением управляющих MCP-инструментов необходимо отдельно спроектировать разрешения, подтверждение операций пользователем, safety interlocks и полный audit log. Наличие токена само по себе не должно давать модели право воздействовать на БПЛА.
