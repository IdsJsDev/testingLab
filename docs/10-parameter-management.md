# Управление параметрами

## Совместимость файлов

Backup сохраняется в текстовом формате Mission Planner (`.param`/`.parm`):

```text
PARAM_NAME,VALUE
```

- одна пара на строку;
- десятичный разделитель — точка;
- не более шести знаков после точки, конечные нули удаляются;
- комментарии при импорте начинаются с `#`;
- сортировка выполняется по частям имени, разделённым `_`, как в Mission Planner.

## Безопасный порядок работы

1. Получить полный список параметров.
2. Сохранить backup перед изменениями.
3. Изменить значения вручную или загрузить файл для сравнения.
4. Выбрать отличия и подготовить их к записи — это ещё не изменяет контроллер.
5. Отдельно подтвердить запись.
6. Каждый `PARAM_SET` считается успешным только после совпадающего ответа `PARAM_VALUE`.
7. Неподтверждённая запись повторяется до трёх раз и затем отмечается ошибкой.

За одну операцию разрешено записать не более 200 параметров.
